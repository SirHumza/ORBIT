# Changelog

## ORBIT 0.1.0

- Establish ORBIT as a separate OpenOrbis PS4 repository with GPL-2 attribution.
- Rename the package identity and CI artifact to `ORBIT.pkg`.
- Add a controller-first, subdued SDL library interface.
- Add a durable FPKGi-shaped sequential queue and bounded download retry.
- Allow BGFT to handle packages whose title is already installed.
- Ship an empty default catalog until entries have verified redistribution authorization.
